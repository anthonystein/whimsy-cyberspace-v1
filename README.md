# Hidden Infrastructure V5

A static website prototype for Whimsy Cyberspace.

## Files
- `index.html`: Main Hidden Infrastructure experience
- `project.html`: Public project map for the Primetime implementation
- `styles.css`: Responsive design system and motion styling
- `script.js`: Scroll reveals, cursor glow, and interactive tilt effects

## Before publishing
Replace `your-email@example.com` in `index.html` with the email address that should receive contribution submissions.

Open `index.html` in a browser to preview the site.
